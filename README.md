# Himnario Cristiano Offline v1.0
PWA local con IndexedDB, himnos editables/importables/exportables y Biblia de Estudio con notas.
**Importante:** la aplicación no incluye el texto completo de Reina-Valera 1960. Debes importar una copia cuyo uso tengas autorizado.
Formato HCO: `{ "format":"HCO", "version":"1.0", "hymns":[ ... ] }`. Un TXT puede contener varios himnos separados por una línea en blanco; la primera línea puede ser `1 - Título`.
